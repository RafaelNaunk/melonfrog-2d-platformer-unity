# melonfrog-2d-platformer-unity
Jogo de plataforma 2D feito em Unity e C# — projeto de Game Development. 🐸 MelonFrog — platformer 2D em Unity com 3 fases, boss e pixel art. Projeto acadêmico de Game Development (UniFECAF). Platformer 2D em Unity (C#): movimento fluido, inimigos, boss com barra de vida, coletáveis e HUD.
